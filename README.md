No Encapsulamento, a interface expõe a propriedade destino, enquanto a implementação esconde o atributo __destino. 
Na Herança, a interface herda nome e caminho, enquanto a implementação reaproveita a estrutura de Item. 
No Polimorfismo, a interface expõe tamanho() e mostrar(), enquanto a implementação define o tamanho fixo de 1 byte.
